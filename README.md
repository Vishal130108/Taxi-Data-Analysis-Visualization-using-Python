# Taxi Trip Data Analysis & Visualization Using Python

## Project Overview

This project presents an exploratory analysis of taxi trip data using Python. The analysis focuses on data quality, trip characteristics, fare patterns, payment methods, pickup locations, and relationships among key numerical variables.

The dataset was processed and analyzed using **Pandas, Matplotlib, and Seaborn**, followed by a range of statistical and visual exploration techniques.

---

## Objectives

- Examine the structure and quality of the taxi trip dataset
- Identify and address missing values
- Prepare timestamp data for time-based analysis
- Analyze fare and trip patterns
- Examine trip distribution across pickup locations
- Understand payment method distribution
- Explore relationships between distance, fare, tips, tolls, and total amount
- Apply appropriate data visualization techniques for exploratory analysis

---

## Data Preparation

The dataset was reviewed for missing values and data quality issues.

Categorical missing values were addressed using appropriate mode-based imputation. The `pickup` timestamp was converted into datetime format to support time-based analysis.

After preprocessing, the dataset was prepared for exploratory analysis and visualization.

---

## Exploratory Data Analysis

### Fare Analysis

Fare patterns were examined across time and pickup boroughs to understand variations in revenue contribution and fare behavior.

### Trip Distribution

Trip volumes were analyzed across pickup boroughs to understand the distribution of taxi activity across different locations.

### Payment Method Analysis

Payment methods were analyzed to understand their distribution across taxi trips.

### Distance Analysis

Trip distance was examined to understand the overall distribution of journey lengths.

### Tip Analysis

Tip values were analyzed across pickup boroughs to examine variation and identify potential outliers.

---

## Relationship Analysis

Relationships between important numerical variables were explored, including:

- Distance
- Fare
- Tip
- Tolls
- Total

Correlation analysis was used to examine the strength and direction of relationships between these variables.

Pairwise relationships were also explored across distance, fare, tip, and total amount, with pickup zones used for categorical comparison.
